#  Shopping Cart System

A desktop shopping cart interface developed using **Java Swing**. This project demonstrates the design of a graphical user interface (GUI) for an e-commerce shopping cart.

The interface allows users to view products, adjust quantities, display prices, and review the total order amount.

---

##  Features

- Shopping cart interface
- Product images
- Product names
- Color selection section
- Increase/Decrease quantity buttons
- Individual product prices
- Total order amount display
- Checkout button
- Java Swing desktop GUI

---

##  Technologies

- Java
- Java Swing
- GUI Development

---

##  How to Run

1. Clone the repository.
2. Open the project in NetBeans, IntelliJ IDEA, or Eclipse.
3. Run the `alisverisSepetiArayuzu1.java` file.
